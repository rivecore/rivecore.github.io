Privacy Policy

Last updated: 2026-10-26

What this app is

Andy Rive Drive Sync is a private configuration of the open-source tool rclone, used solely by the band Andy Rive to synchronize and back up its own files in its own Google Drive.

Data accessed

The app requests access to Google Drive (scope https://www.googleapis.com/auth/drive) in order to list, read, upload, update and delete files in the authorizing user's Drive.

How data is used and stored

  • Files are transferred only between Google Drive and computers controlled by the band.
  • OAuth tokens are stored locally in the rclone configuration on those computers.
  • No data is sent to any server operated by us or by third parties.
  • No data is sold, shared, or used for advertising or analytics.

Google API Services User Data Policy

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
